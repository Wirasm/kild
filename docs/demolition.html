§06

The attached-harness contract

The pi extension is kept and rebuilt — but reframed. It is not "the operator tier for pi"; it is the pi implementation of the attached-harness contract, exactly peer to Claude Code's.

The engine defines one contract for any harness it does not own: attach a handle to a kild (addressable immediately, nothing spawned) · drain its inbox at its own turn boundary · act through the same spawn / send / observe / land API every client uses.

Harnessattach + drainact
Claude Codehooks/claude-stop — Stop hookkild CLI over bash (kild-cli skill)
pithe extension's WS event bridge, natively at the turn boundarykild_* native tools

pi's is the better integration — a native turn-boundary drain instead of a shell hook — which is exactly why the extension earns its keep. A third harness later is a third implementation of the same contract, not a third mechanism in the engine.

Mechanism only

The extension ships tool definitions plus the event bridge — nothing else. Any pi session can therefore be a honryo: it becomes one by wearing PRP's honryo persona, not by an engine flag. Same rule as everywhere else — authority is trained deference, never a capability the engine grants.

§08

Order of operations

Each step is a green-gates checkpoint (bun test · typecheck · lint). Nothing here is a shim; every rename is a real move.

  1. Cut the Flue lane
    Isolated, zero behaviour change. Gets the tree honest before the real work.
  2. Rename the domain
    Room→Kild, RoomParticipant→Agent, RoomMessage→Message, spawned/attached→owned/attached. Mechanical; gates stay green.
  3. Delete the addressing choreography
    room-router, the lead, implicit replies, HUMAN. Replace with directed send. The recurring addressing bug class dies here.
  4. Collapse the tiers
    Delete operator/* and the operator worker branch. invite_agent + open_room → one spawn; post_message + post_room → one send.
  5. Move intelligence out
    room-decisions, the idle-nudge failsafe, memory synthesis → PRP.
  6. Reshape the surfaces
    server routes, CLI verbs, pi-extension (or retire it), hooks/claude-stop.
  7. Add the new mechanism
    /api/kilds/:id/land plus seat guardrails: push-protection, spend cap, hard-halt.

The substrate was never the problem. Isolation, supervision and observability stay exactly as they are — what comes out is the org chart that grew on top of them.
